# ⚔️ Solo Leveling System — Gamified Task Tracker & Shop App

Интерактивное веб-приложение, объединяющее **игровую механику "Системы" из аниме Solo Leveling** с полным функционалом **Трекера задач (Task Tracker)** и **Магазином наград ("Хотелки")**.

---

## 🔥 Ключевые возможности

### 1. ⚔️ Механика прокачки и Статы (Solo Leveling System)
* **Динамическая прогрессия уровней (от 1 до 100+)**: Уравнение экспоненциального роста опыта ($100 \times \text{Уровень}^{1.5}$). Каждый следующий уровень дается тяжелее предыдущего.
* **Звания Хантеров**: Автоматическое присвоение рангов:
  * `E-Rank` (Уровень 1-10) — Новичок E-Ранга
  * `D-Rank` (Уровень 11-25) — Искатель D-Ранга
  * `C-Rank` (Уровень 26-40) — Боец C-Ранга
  * `B-Rank` (Уровень 41-60) — Авангард B-Ранга
  * `A-Rank` (Уровень 61-80) — Командир A-Ранга
  * `S-Rank` (Уровень 81-99) — Охотник S-Ранга
  * `MONARCH` (Уровень 100+) — **Теневой Монарх (Shadow Monarch)**
* **Характеристики (Stats)**: 5 параметров с ручным распределением очков (по +5 очков за уровень):
  * 🗡️ **Сила (STR)**: Увеличивает доходность Золотых монет (+2% за очко).
  * ⚡ **Ловкость (AGI)**: Увеличивает скоростной бонус опыта.
  * 👁️ **Восприятие (SEN)**: Дает шанс Критического удвоения наград (x2 XP и x2 Золота).
  * 🧠 **Интеллект (INT)**: Увеличивает общий множитель Опыта (XP).
  * 🛡️ **Выносливость (VIT)**: Защита серии выполнения квестов и снижения штрафов.

### 2. 📋 Трекер задач (Task Tracker)
* **3 Вида отображения**:
  * 📋 **Список (List View)**: Удобный список с фильтрацией и быстрого завершения задач.
  * 📌 **Канбан Доска (Kanban Board)**: Колоночное отображение (`К исполнению` ➔ `В процессе` ➔ `Выполнено`) с поддержкой Drag & Drop.
  * 📅 **Календарь (Calendar View)**: Сетка месяца с визуальным отображением задач по срокам.
* **Ранги задач (E, D, C, B, A, S)**: Чем выше сложность/приоритет задачи (вплоть до S-Rank Boss Quest), тем больше XP и Золота вы получаете.
* **Категории с цветовой кодировкой**: Здоровье & Спорт, Работа & Кодинг, Обучение & Книги, Быт & Личное и др.

### 3. 🔥 Ежедневные Квесты (Daily Quests Log)
* Вдохновлены культовой тренировкой Сон Джин-Ву (100 отжиманий, 100 пресса, 100 приседаний, 10 км бега).
* Подсчет непрерывной серии дней (Streak counter) и бонусные награды за полное закрытие дневного комплекса.

### 4. 🛍️ Магазин Наград ("Хотелки")
* За выполнение задач вы получаете не только XP, но и **Золотые монеты 🪙**.
* На монеты вы можете покупать **свои собственные хотелки**, которые сами добавили в магазин (например: *"Поиграть в PS5 2 часа"*, *"Заказать пиццу"*, *"Купить новую вещь"*).
* Раздел **Купленные Награды (Inventory)** хранит историю ваших разблокированных радостей.

### 5. 🔊 Звуки и Визуальные Эффекты
* Голографический неоновый интерфейс в стиле "Системы".
* **Web Audio API**: Футуристичные звуковые эффекты (Level Up фанфары, выполнение квеста, покупка в магазине, распределение статов).
* Анимированный салют / частицы при получении уровня.

### 6. 💾 Сохранение и Экспорт
* Автоматическое сохранение в `localStorage` вашего браузера.
* Функция **Экспорта / Импорта JSON** (чтобы вы могли бэкапить данные или переносить их на другие устройства).

## 🚀 Как запустить приложение локально

Так как приложение написано на чистом HTML5, CSS3 и Vanilla JavaScript (ES-модули):

1. **Просто откройте файл `index.html`** в любом современном браузере (Chrome, Safari, Edge, Firefox).
2. Или запустите локальный сервер:
   ```bash
   python3 -m http.server 8000
   ```
   И откройте в браузере: `http://localhost:8000`

## 🐙 Как выложить на GitHub (GitHub Pages)

Чтобы ваше приложение было доступно по ссылке в интернете:

1. Инициализируйте репозиторий:
   ```bash
   git init
   git add .
   git commit -m "Initial commit: Solo Leveling Task Tracker & Shop App"
   ```
2. Создайте новый репозиторий на GitHub и привяжите его:
   ```bash
   git remote add origin https://github.com/ИМЯ_ПОЛЬЗОВАТЕЛЯ/solo-leveling-tracker.git
   git branch -M main
   git push -u origin main
   ```
3. Зайдите в настройки репозитория на GitHub: **Settings -> Pages -> Branch: main -> Save**.
4. Ваше приложение будет доступно по адресу `https://ИМЯ_ПОЛЬЗОВАТЕЛЯ.github.io/solo-leveling-tracker/`!
